# v8 风格适配评分标准与重评验证

2026-10-06。内部证据记录；本轮改评分标准，模型仍为 GPT-6 Luna。发布状态以文末核验为准。

## 修复范围

截图中的照片已使用 v7/GPT-6，并非未迁移的 v5。旧评分把深色前景缺少纹理、克制的色彩或非叙事风光当作减分理由，部分理由与点评中认可的画面效果矛盾。v8 要求按元素的实际作用判断：

- 黑白、同色系和低饱和色彩可以通过层次、组织和情绪表现支撑高分，不要求更多颜色。
- 暗部、轮廓、远景雾气和边缘裁切只有损害重要信息或关系时才扣分；不得凭无法确认的细节损失扣分。
- 风光的光线、尺度、节奏与气氛可以体现感染力；常见题材和缺少人物故事本身不是缺陷。
- 可选的小幅调整不等于执行不足。同一问题影响多个维度时须说明各自实质损害；没有明显不足时可以明确写出，不能为填满字段制造批评。

五维整数、算术均分、原有分数锚点、图像输入、结构化 schema、`xhigh` 与 >=8 的中性独立复核均保留。没有统一加分、强制最低 8 分或把用户期望的分数输入模型。无缺陷本身不自动取得高分。scorer 合同更新为 `score-v8-style-relative` / `photo-score-v8-style-relative`，writer 保持 `photo-review-v9-gpt6-image-led`。缓存、checkpoint 和成长统计按精确版本隔离。

## 冻结实验与独立验证

开发集是截图中六张图，同场景的黑白和彩色雪峰作为同一内容组。每个版本每张独立请求三次，绕过缓存。严重信息损失的既有控制图在 v8 中技术分三次均为 2，总分为 4.0 / 5.0 / 4.4，说明规则没有取消实际技术损伤扣分。

在查看验证结果前冻结候选、采用门槛与 16 张未见 AVA 图片；来自镜像 test rows 500–799，四个均分区间各四张，共 3228 个既有众评投票。按图片 ID、字节与 RGB 哈希排除所有先前实验及开发图，标签不进入评分输入。每个版本每张三次，共 96 条完整输出。

预先固定的本轮采用门槛是三个指标不退步且无缺失/失败样本，结果 `PASS_NONREGRESSION`。旧通用诊断门槛要求相关性增加至少 0.10，本轮仅增加 0.0421，按那个门槛仍为 `NO_IMPROVEMENT`。正式 PicSpeak 人工校准仍为 `INSUFFICIENT_INVALID`；这些小样本结果支持采用针对性规则修复，不证明全站准确率、专业评审一致性或全部题材均改善。
